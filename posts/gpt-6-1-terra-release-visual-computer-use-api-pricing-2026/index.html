GPT-6.1 Terra 发布：视觉操作升级，API 标准价是 Sol 的一半

狂人哥2026-10-28— 次阅读
SI&AI资讯

OpenAI 这次推出的 GPT-6.1 Terra，把重点放在了日常工作里很常见的一件事：看懂屏幕上的信息，再把操作做完。

在发布说明中，OpenAI 将它定位为兼顾速度、成本、视觉推理与电脑操作的模型。提案写作、技术图纸理解、表单填写、视频编辑，都被列为目标工作场景。官方本周更新已确认，它正在 ChatGPT Work、Codex 和 API 提供使用。

最吸引人的价格信息也能核对：按当前标准短上下文报价，Terra 的输入与输出单价，都是 GPT-6.1 Sol 的一半。不过，模型单价、完成一次工作的总成本，以及订阅套餐消耗，是三件需要分别看的事。

视觉能力为什么要和电脑操作一起谈？

看懂一张截图，只是工作的一部分。要把信息填进表格、在软件里调整素材，还得能找到对应控件、执行操作，并检查保存后的结果。

官方电脑操作文档描述了这样的循环：模型接收当前画面，提出动作，连接的浏览器或桌面环境执行动作，再返回新的截图。这个过程说明，实际表现同时依赖模型和执行环境；最终文件是否正确保存，比最后一句“已完成”更有说服力。

因此，发布文里的“编辑视频”，也要结合产品形态理解。Terra 模型规格页列出的直接输入是文本和图片，输出是文本，并不支持原生音频、视频输入输出。让智能体通过工具操作视频软件，与直接生成一段视频，属于不同能力。

用一个假设场景理解：商家要把供应商图册中的商品照片，与现有目录逐项对应，再更新商品信息。模型要辨认图片里的款式与颜色，找到匹配记录，填写字段，还要核对最终保存结果。相似款混在一起、页面加载失败或字段含义不清，都会影响交付；这也解释了为什么视觉成绩与完整操作能力要同时考察。这个例子用于说明工作链条，并非本文实测。

OpenAI 报告，在 Agents’ Last Exam v1 的中等思考设置下，Terra 比 GPT-5.6 Terra 高15个百分点，成本约为后者三分之一。这是厂商在指定评测与配置下的结果，本文没有独立复测。

Agents’ Last Exam 原始论文强调的，是能交付、可核验的专业工作流程：任务可能同时需要图形界面、代码、文件处理和多轮检查。它也区分完整通过与部分得分。读这种成绩时，评测版本、代理框架和思考档位都应保留，不能直接换算成所有软件任务的成功率。

论文还有一个具体例子：单独在视频里套滤镜，范围过窄；把一段奔跑的猎豹移入另一段比赛视频，则涉及跟踪、抠像、合成与颜色匹配。研究者关注这样的完整交付链条。它说明，能够调用某个按钮，与最终产出合格素材之间，还隔着多个需要检查的环节。

对照 Sol，半价怎样落到账单里？

当前官方价格表给出的标准短上下文报价如下，单位均为每百万 token：

计费项目 GPT-6.1 Terra GPT-6.1 Sol
未缓存输入 1美元 2美元
缓存命中输入 0.05美元 0.10美元
输出 5美元 10美元

这里的“半价”有明确参照：相同计费档位下，与 Sol 比较。发布文对旧版 Terra 的降幅采用概括表达，而当前价格表中旧版输出等项目的比例并不完全相同，因此本文不把它们统称为统一五折。

举一个假设账单：一次请求使用10万未缓存输入 token、1万计费输出 token，按上表计算，Terra 为0.15美元，Sol 为0.30美元。这个例子只比较所列模型用量，不包含缓存写入、工具或其他资源费用，也不是实测任务消耗。

如果换用不同模型后，思考长度、尝试次数或返工量发生变化，总价也会变化。一个便宜的单次请求，可能需要多跑几次才能得到合格文件；一个较贵的模型，也可能较快解决复杂问题。判断应落在同一任务的合格产出、耗时和总用量上。

还有一个容易漏看的条件：模型规格注明，超过272K输入 token 的请求，对整次请求应用长上下文费率，输入与缓存费率为常规的2倍、输出为1.5倍。缓存命中价也要与缓存写入价分别看，不能把低命中单价理解成所有输入都按这个价格收费。

Work、Codex 与普通聊天，入口各有范围

ChatGPT Learn 的10月26日至30日更新列出，Terra 面向 Plus、Pro、Business、Enterprise 和 Edu 的 Work、Codex 用户提供，普通 Chat 不包含这个模型。企业工作区还受管理员设置和可用范围影响。

OpenAI 在发布文中表示，相同使用额度可让 Terra 完成更多任务。这描述的是效率方向，并没有给出适用于所有任务的固定倍数。API 价格表也不能直接换算成每个订阅用户每天多出多少次操作。

对已经使用 Sol 的人，Terra 增加了一个值得比较的选项：资料清楚、操作目标明确、结果容易核验的视觉工作。复杂项目仍可结合本站此前的 GPT-6.1 Sol 定位解读判断。比较时，选取同一份材料和验收标准，才更容易知道节省的是费用、等待时间，还是只是一次请求的单价。

核查截至2026年10月28日。主来源之外，已核对模型规格、价格表、本周产品更新、电脑操作文档和 ALE 原始论文；性能数字为厂商评测，费用例子为本文按公开报价计算。
