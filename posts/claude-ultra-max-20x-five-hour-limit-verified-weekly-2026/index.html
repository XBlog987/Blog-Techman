Claude 200美元档改名 Ultra：取消五小时限制，为何仍会用完？

狂人哥2026-11-01— 次阅读
SI&AI资讯

最让重度 Claude 用户烦躁的情况，未必是一周的额度用完，而是项目刚做到一半，五小时窗口先亮了红灯。Anthropic 这次调整的，正是这种“还有周额度，却得先停一停”的工作节奏。

北京时间10月31日凌晨，Claude 官方在 X 公告中宣布：100美元的 Max 5x 改名 Max，200美元的 Max 20x 改名 Ultra；现有订阅自动迁移，价格不变。更实质的变化是，已验证 Ultra 账号开始取消五小时限制，官方明确表示周额度不变。

图源：Claude 官方账号 @claudeai 的上述原帖配图，11月1日核查。这张图说明套餐名称层级，具体额度和验证条件以官方帮助页为准。

去掉短时限制，为什么还是可能停下来？

按现行价格表，两个高用量个人档现在的核心区别如下。金额为网页订阅月价，移动端价格可能不同。

套餐 网页月价 五小时限制 周用量口径
Max 100美元 保留 Pro 的5倍
Ultra 200美元 已验证账号取消，未验证账号暂时保留 Pro 的10倍

这里最值得留意的是最后一列。“没有五小时限制”允许用户在一周的预算内，更自由地安排集中工作；它没有把周预算也一起拿掉。Ultra 官方说明还列有跨模型的周上限，以及 Fable 单独的周限制，并保留为管理容量和公平访问而设置其他限制的可能。

不妨设想两位使用习惯不同的人。一位平时只做少量问答，周末需要连续几小时改代码，过去容易先撞到短时限制；另一位每天高强度使用，原本每周就会把预算消耗完。前者能更灵活地安排工作，后者不会因为套餐换了名字，就凭空得到更多每周用量。这个例子解释的是规则效果，不是对任何账号的额度测算。

周额度的重置也有独立时钟：官方用量文档说明，每个账户有固定的每周重置时刻，并不随着当天第一次提问或开始订阅而重新计算。安排长任务时，剩余周量和下一次重置时间应一起看。取消短时限制之后，这个周计划反而更重要，因为用户可以在较短时间里花掉更多预算。

旧名叫“20x”，新文档写“每周10倍 Pro”，也不能直接算成减半。比较数字之前要先确认统计周期与参照口径；这次官方原帖给出的关键事实是周额度未变。用名字里的两个数字代替规则核对，反而会错过真正发生的改变。

100美元档的规则则没有跟着取消。Max 帮助页仍列出每五小时及每周两道限制。对只打算升级到 Max 的人来说，看见 Ultra 新闻标题便以为自己也能连续使用，是最容易踩中的误区。

“已验证”并不是让你重新认证手机号

本轮新规带有账户条件。Anthropic 根据账号、付款历史等因素自动验证 Ultra 账户；新账号在完成之前，可能继续受到临时限制。帮助页说明用户无需额外操作，结账时的手机号验证也是另一项流程，不能用来直接取消这个临时限制。

官方提供的识别方法很简单：看设置里的用量页面。如果已不再显示“当前会话”进度条，说明账号已经通过这项验证。这里是在解释官方判断依据，并不代表本站已经替某位读者检查了账户。

公告没有给出对所有新账号统一适用的等待天数，因此不能保证“购买后几天必定解除”。官方 X 原帖称会在临时限制移除时发送邮件。已经付费但仍看到会话进度条的人，应先分清临时状态与周额度，而不是不断提交手机号，或寻找所谓人工开通捷径。

还需要分开看的是周额度与单次对话长度。用量和长度说明指出，上下文窗口决定一段对话能处理多少内容；用量限制决定一段时间内能工作多少。取消五小时限制，既不意味着上下文无限，也不意味着每条消息的消耗固定。模型、任务复杂度、对话长度和思考设置都会影响用量。

对 Claude Code 用户，改变在“何时用”，不在“换入口”

Claude Code 订阅说明确认，使用同一订阅登录时，网页、桌面和编程工具的活动共享相关上限。把任务从聊天页面搬到终端或 IDE，不会再得到一份独立的周预算。连续编程更顺畅与总量不再受限，是两回事。

另外，Ultra 所含的每月200美元 API 抵用额度有单独的领取和使用规则。API 权益说明要求符合资格并关联 Console 组织；这些额度用于平台 API 等场景，不覆盖互动式 Claude Code 或订阅超限后的额外用量，也不改变原有周限制。把它当作聊天窗口里的另一份200美元余额，会误算套餐的实际可用量。

近期，另一边的ChatGPT Pro 200 额度调整也发生反转。两条新闻放在一起，说明高价 AI 订阅的体验不能只看月费或模型名单：限制按什么周期重置、哪些工具共享额度、何时允许集中使用，同样会决定服务是否适合一个人的工作习惯。这是对产品变化的比较，不是对两家公司决策因果的推断。

Ultra 本轮最明确的收益，是让已验证账号更容易把一周用量花在真正需要的时段。是否值得多付100美元，仍要看自己经常碰到的是五小时阻挡，还是周预算耗尽；改名本身不会替用户回答这个问题。
