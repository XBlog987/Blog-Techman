MiniMax M3.1 Flash 正式发布：“太空兔”揭晓身份与价格

狂人哥2026-10-20— 次阅读
SI&AI资讯

“太空兔”终于有了正式身份。

10 月 19 日，MiniMax 发布 M3.1 Flash，确认此前匿名运行的 Space Bunny 是它的早期版本。官方发布说明同时列出了自营 API 价格、MiniMax Code 等使用入口，以及稍后开放权重的计划。这让一款靠匿名体验积累关注的模型，进入了有明确品牌和报价的正式产品阶段。

这次发布主攻的是多步骤工作：操作工具、处理代码库、跨应用完成任务。对关心 AI 能否真正干活的读者，值得看的问题也随之变化：匿名测试时觉得好用，变成日常工作中的付费服务后，优势能否保留下来？

揭晓身份之后，要交付的是一整套产品

据 路透社 10 月 19 日的报道，MiniMax 宣布了这次更新，称其在智能体任务、编程与网络安全等方向有所提升。报道中的提速和降本数字来自公司声明，并不是路透社独立运行模型后的结论。

开发者模型目录将 M3.1 Flash 列为支持百万 token 上下文、可调思考深度的多模态编程模型；接口文档进一步列出了图像、视频与工具调用等输入内容支持。这些信息说明，产品定位覆盖了需要连续读取资料、观察界面和调用工具的任务。

例如，让助手修一个跨多个文件的错误，它不只要生成补丁，还要理解上下文、运行检查，再根据失败结果修改。这个假设场景中的等待时间和花费，会由一连串步骤累积而成，单看某一次回答很快，并不能概括整项工作的体验。

交付状态也要分清。主发布页明确写的是 API、M Plan 和 MiniMax Code 已提供入口，模型权重稍后发布。虽然发布记录使用了开放权重模型的定位表述，当前报道仍应保留“稍后”的时间条件，而不能凭一个产品标签推断已经完成权重交付。

低价写在报价单上，降本发生在任务里

截至 10 月 20 日核查，MiniMax 自营 API 价格页列出的 M3.1 Flash 标价为：每百万输入 token 0.15 美元，每百万输出 token 0.60 美元，每百万缓存读取 token 0.015 美元。

这三项是不同的计费部分。反复使用已经命中的上下文，可能减少输入费用；推理过程、最终回答以及后续步骤产生的用量，则仍要看实际账单。

只为说明单位，假设某次调用用了 1 万个未命中缓存的输入 token，加 2000 个输出 token，按上述标价计算为 0.0027 美元。这不是本站实测，不包含额外工具或重试，也不是一整项编程任务的固定价格。

MiniMax 所称的“使用成本降低 70%”，是它对智能体任务整体成本的描述。从账单构成看，无效尝试次数、生成用量和单价都会影响花费；发布页的整体成本宣传，并不能换成每个用户都会节约同一比例的承诺。

图：MiniMax 发布的原始对比图，核查于 2026 年 10 月 20 日。横轴为每项任务的平均美元成本，使用对数刻度；图注注明数据截至 10 月 18 日、Automation-Bench v1.0.6、评测运行框架为 Claude Code，并对 DeepSeek 使用高峰报价。它属于厂商评测，不能当作独立排名或个人账单保证。来源

这张图值得看的，是同一模型不同推理档位也会落在不同位置。换一个档位，消耗和得分都可能变化；换成其他使用时段的实际报价，比较关系也可能改变。

AutomationBench 的原始说明描述的是模拟商业环境中的工作流，并区分公开任务集与官方榜单使用的私有任务集。因此，读图时需要连同版本、任务集、评分方法和运行框架一起看，不能把图中的百分数直接当作真实公司里所有工作的完成率。关于任务成本与 token 单价的区别，也可对照站内的 DeepSeek 1017 更新分析。

“Flash”还要回答：到底在哪个环节快？

官方发布页称，日常输出可以达到每秒 200 多个 token，中位速度达到每秒 170 多个 token。它描述的是厂商给出的线上生成表现。

而在 10 月 20 日核查时，OpenRouter 的 M3.1 Flash 入口当前 P50 表格显示吞吐约为 100 tps，页面另列了时延信息。请求分布、推理设置和统计窗口可能不同，两个数字不能直接互换，也不足以据此计算平台之间的速度差。

更影响体验的细节藏在接口说明里：M3.1 Flash 的思考不能关闭，思考深度可以调整，省略时默认为最高的 max 档。文档说明，更高档位会产生更多思考 token，并增加时延。模型输出得快，与让它用最高档完成一项长任务需要多久，是两项需要分别观察的指标。

OpenRouter 当时将相应入口列为免费；这是该入口当前的价格展示，与 MiniMax 自营 API 的正式标价应分开记录。本文没有调用接口测试速度，也不把当前免费展示解释为永久承诺。

匿名口碑之后，竞争落到持续可用

从匿名版本到正式发布，MiniMax 增加了一种低单价、面向长工作流的模型选择。本文的判断是，它对市场更直接的压力，来自“把多步骤工作做到多便宜”，而非再提供一个抽象的聊天跑分。

接下来比单张榜单更有价值的，是稳定性、失败后的恢复、同一批任务的完整花费，以及权重实际交付后的部署条件。这些都需要继续观察。对已经体验过“太空兔”的用户，正式版值得重新比较；但比较时应保留相同任务、推理档位和完整用量，才能知道模型发布后的变化，是否真的落到了自己的工作里。
