美团发布 LongCat-2.5：1.6万亿参数背后的多模态长任务路线

狂人哥2026-11-03— 次阅读
SI&AI资讯

11月2日，美团发布 LongCat-2.5，把原生视觉理解、编程和长程智能体任务放在同一条产品路线上。美团官网刊载的发布材料称，模型总参数达到1.6万亿，训练全程使用国产算力，并将能力延伸到软件开发和商家经营工作流。

这次值得关注的，不只是参数规模。一个模型能否连续读资料、调用工具、检查结果，最终交出可使用的网页、项目或经营分析，比单次回答漂亮更接近真实工作的要求。龙猫这轮发布，主要想解决的是这样的连续交付问题。

先分清9月预览与11月正式发布

LongCat-2.5 并非一个今天才出现过的名字。官方接口更新日志保留了9月25日上线 LongCat-2.5-Preview 的记录；IT之家当时的报道也记载，预览阶段已经开放网页和 API 体验，并增加图片理解与编程能力。

本轮技术博客标注11月1日，11月2日的接口日志则列出 LongCat-2.5 正式可用。因此，新闻的新意在于这次正式发布及配套披露，不能把9月已经存在的预览入口，重新说成今天首次开放。

现行官方接口文档列出的模型标识为 LongCat-2.5，并支持 OpenAI、Anthropic 两类常见接口格式。这有利于开发者把模型接进现有工具，减少重新搭建接入层的工作；至于替换后效果是否更好，仍取决于模型与任务，而不只看接口是否兼容。

大参数模型，重点落在多模态与长任务

技术博客披露，LongCat-2.5 采用混合专家架构，总参数1.6万亿，每个 token 激活约480亿参数。可以把它理解成一个规模很大的专家团队，每次处理信息时调用其中一部分。总规模与每步参与计算的规模不同，不能简单用其中一个数字判断全部部署成本。

视觉方面，团队把图像表示成模型可以处理的离散 token，让视觉与文本进入统一的处理框架。对普通用户，真正可感知的变化是：任务不必全靠文字描述，可以结合图像理解来制作网页、分析界面和完成视觉编程。

长任务方面，团队介绍了较长的训练轨迹、大规模强化学习，以及把真实 Agent 的失败过程转化为可复现、可验证任务的方法。它们针对的常见问题是：模型可能第一步做对了，却在后续操作中重复调用工具、丢失目标，或交付一个不能正常运行的半成品。

例如，做一个交互式页面，不只是生成一段 HTML。系统还可能需要处理布局、脚本、视觉效果与检查反馈。龙猫的发布材料把完整项目构建和复杂代码库工作列为训练重点。这说明它的竞争目标已经超出补全几行代码，但训练方向本身还不能证明所有实际项目都能稳定完成。

图源：LongCat-2.5 技术博客所附官方演示视频封面，11月3日核查。图中展示模型生成的交互网页案例，属于厂商演示，并非本站实测；静帧也不能证明运行流畅度或任务成功率。

100万上下文与开放权重，要分别核对

长程任务需要较大的信息窗口。当前接口文档列出100万 token 上下文和128K token 的最大输出长度。前者描述模型可处理的信息窗口，后者描述输出上限；它们也都不能直接换算成同样数量的中文汉字。

技术材料同时讨论了长序列训练、国产算力上的显存和通信优化，以及 W4A4 低位宽推理。这些是支撑运行效率的工程安排。厂商披露的吞吐提升有特定基线和测试负载，不宜直接改写成“所有用户都会提速相同比例”，也不能从480亿激活参数推导出普通显卡就能轻松本地运行整个模型。

至于开源，11月2日的报道和技术博客页面均把 GitHub、Hugging Face 标为后续安排或敬请期待。截至本文核查时，应把网页/API 可用与权重已经公开分开描述；LongCat 家族此前的开源项目，也不能替代这个版本的实际交付记录。

能力展示之后，还要看工作流中的表现

龙猫博客给出了多项评测，但脚注说明：部分对比成绩来自公开报告或榜单，另一部分由团队自测，不同任务还使用了不同的智能体框架与设置。这些数据有参考价值，身份仍是厂商披露，不能包装成本站独立测评或对所有最新旗舰的全面胜出。

美团同时把模型与“妙手”经营工作台联系起来，展示经营核算、问题诊断和资源配置建议等案例。对商家，重要的可能不是 AI 能写出多长的报告，而是它能否读对原始数据、遵守业务口径，并在授权范围内把建议接到实际流程。样例展示了方向，长期使用效果仍需更多真实结果。

站内此前介绍的DeepSeek Super-agent 原型，从系统层面组织多个任务与会话；LongCat-2.5 则着重增强模型本身的多步执行能力。两类进展可以相互配合，也提醒我们：一个可长期使用的 AI 助手，既需要模型能力，也需要可靠的工具、权限和交付流程。

这次发布为国内多模态长任务模型增加了一个值得观察的选择。接下来最有价值的进展，是后续 GitHub、Hugging Face 入口具体交付什么代码、权重或许可材料，以及它在不同代码库、真实资料和持续工作中的稳定性，而不仅是一张更大的参数表。
